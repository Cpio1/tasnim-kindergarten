# «Тасним» бөбекжай-балабақшасы — сайт

Next.js 15 (App Router) · TypeScript · Tailwind CSS v4 · Framer Motion · Lucide React. Деплой — Vercel (настройки по умолчанию).

```bash
npm install
npm run dev        # http://localhost:3000
npm run typecheck
npm run build
```

## Устройство

- `src/website/` — версия для ноутбуков и мониторов (≥ 1024px; масштаб подобран под 1366×768 и 1440×900 —
  каждая секция ниже высоты экрана).
- `src/mobile-website/` — отдельная композиция для телефонов (< 1024px; проверено на 320, 375, 390 и 430px).
- `src/shared/` — общее: факты (`data/kindergarten.ts`), все тексты на казахском (`data/content.ts`), SEO (`data/seo.ts`),
  декоративные фигуры (`ui/Decor.tsx`), галерея, просмотрщик, карта, хуки.
- `src/shared/ui/LayoutSwitch.tsx` выбирает версию по ширине экрана (media query, не user agent).
  Сервер отдаёт обе, CSS сразу показывает нужную, после загрузки лишняя версия удаляется из DOM.

Все факты — только в `kindergarten.ts` и `content.ts`. Названия групп, педагоги, лицензии не указаны:
в разделе «Біздің топтар» карточки «1-топ … 6-топ» с пометкой «Атауы жақында жарияланады».
Когда названия появятся, их нужно будет добавить в `content.groups` (`src/shared/data/content.ts`) и вывести в карточках `Groups.tsx` / `MobileGroups.tsx`.

## Фотографии и видео

Положите файлы в `public/images/` (видео можно и в `public/videos/`) и задеплойте заново — код менять не нужно.
Пока файлов нет, вместо фото показываются иллюстрации-заглушки, а в галерее — ссылка на Instagram.

| Файл | Где используется |
| --- | --- |
| `main-page.*` | главный экран (фото или видео) |
| `main-page2.*` | фото → раздел «Біз туралы»; видео → маленькое беззвучное видео на главном экране |
| другие фото | галерея, по имени файла (`image1.jpg`, `image2.jpg`, …); сначала 5, остальные — «Тағы көрсету» |
| другие видео (`.mp4`, `.webm`, `.mov`) | блок «Бейнежазбалар» под фото; запуск по нажатию, со звуком |

- Если `main-page2` нет, в «Біз туралы» встаёт первое фото галереи.
- Пропорции определяются автоматически; фото другой формы не обрезается, а вписывается целиком на размытом фоне.
  Полный размер открывается в просмотрщике (Esc, стрелки, свайп).
- Next.js отдаёт фото в AVIF/WebP нужной ширины; фото галереи грузятся лениво.
- Обложка для видео: `<имя>-poster.jpg` рядом с видео.

## Документы (Google Drive)

Вставьте ссылку на папку в `kindergarten.documents.driveUrl` (`src/shared/data/kindergarten.ts`).
Пока ссылка пустая, кнопки нет — показывается пометка «Құжаттар қалтасының сілтемесі жақында осында қосылады».

## Карта

Интерактивная карта Яндекса (без ключа), метка по координатам `kindergarten.geo`.
Карточки «Тасним» в 2ГИС/OpenStreetMap пока нет, поэтому сейчас метка стоит на середине улицы Желтоқсан
в Балпық би (OSM way 385737542). Уточните точку дома 2Б: в Яндекс Картах правый клик по зданию → «Что здесь?» →
скопируйте координаты в `geo` (`lat`, `lng`). Кнопки «2ГИС-те ашу» и «Яндекс Карталар» ищут адрес в самих сервисах.

## Деплой на Vercel

1. Залейте репозиторий на GitHub и импортируйте его в Vercel — настройки по умолчанию (Framework: Next.js).
2. Для своего домена задайте `NEXT_PUBLIC_SITE_URL` (например `https://tasnim.kz`) — от него строятся canonical,
   sitemap и Open Graph. Без переменной используется домен Vercel.
